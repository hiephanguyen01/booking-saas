# Task 1.2 — Partner onboarding & verification

**Phase:** 1 — Studio MVP · **Depends on:** 1.1 · **Design refs:** TONG-QUAN.md §7 (partners, agreement_acceptances, payout_info)

## Goal
Partners (individual/company) can sign up, get approved by the tenant, and are ready to publish listings.

## Scope
- [ ] Partner signup + tenant approval queue; `individual` / `company` types
- [ ] **House partner** (tenant acting as its own partner)
- [ ] Fee-schedule agreement acceptance (`agreement_acceptances`) recorded at approval
- [ ] `payout_info` (bank account, name matching)
- [ ] Identity verification for people-booking listing types: ID document + DOB, **block under-18**; manual review (eKYC is Phase 3)

## Definition of Done
- A partner can go from signup → approved → able to create listings; unverified partners blocked from people-booking types
