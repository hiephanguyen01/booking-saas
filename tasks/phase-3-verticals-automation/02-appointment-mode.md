# Task 3.2 — Appointment mode (staff scheduling)

**Phase:** 3 — Verticals & Automation · **Design refs:** TONG-QUAN.md §9.3

## Goal
Service + staff-member scheduling (salon/spa style) as a first-class mode.

## Scope
- [ ] `appointment` mode: services with duration, staff members as schedulable resources, staff↔service mapping
- [ ] Customer picks service → staff (or any) → slot; staff working hours + time-off
- [ ] Partner dashboard: per-staff calendars
- [ ] Note: freelancers already work via hourly mode since Phase 1 — this mode targets multi-staff businesses

## Definition of Done
- Double-booking impossible across a staff member's services; "any staff" assignment picks a free member correctly
