# Task 3.4 — Tenant self-serve signup + trial

**Phase:** 3 — Verticals & Automation · **Design refs:** TONG-QUAN.md §21

## Goal
New tenants onboard themselves with a trial — no platform-admin involvement.

## Scope
- [ ] Public signup: create tenant + admin user, default subdomain, template choice, trial subscription
- [ ] Onboarding checklist (theme, first listing type, first partner/listing)
- [ ] Trial expiry → conversion flow into automatic billing (task 3.3); abuse guards (rate limit, email verification)
- [ ] Admin health board already tracks trials (Phase 1) — wire signups into it

## Definition of Done
- A stranger can sign up and take a real booking on their subdomain the same day, untouched by an admin
